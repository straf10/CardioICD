CardioICD

Automatic ICD-10 coding of Greek cardiology discharge summaries.

1st place · BioASQ / CLEF ELCardioCC 2026 · micro-F1 0.8667
Interactive examples. These discharge summaries are synthetic, written for this page, so no patient data is involved. The codes and evidence were produced by the demo version of the system, which combines four of our components and is somewhat less accurate than the full model. To code your own text, run the demo locally. Research demo, not for clinical use.

Scored against the diagnoses written into each note, with the official group-level rule: an expected group counts as found if any one of its codes is predicted.
